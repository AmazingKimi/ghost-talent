This file keeps the public positioning consistent across the repository, GitHub About, Topics, release copy, and social sharing.

## Category

**Open-source emerging talent intelligence.**

## Primary tagline

**Discover exceptional AI engineers and researchers before they become obvious.**

## Short description

Evidence-grounded discovery for rising AI engineers and researchers from GitHub and public research signals.

## One-sentence category definition

Ghost Talent starts from a technical frontier and looks for people whose demonstrated capability and momentum are rising faster than their public visibility.

## Category contrast

**Recruiting Search:** I need a CUDA engineer. Who matches the role?

**Emerging Talent Intelligence:** In CUDA / Triton / inference, who is getting stronger before the market notices?

## Public claim discipline

Do not claim that no similar product or project exists. Prefer:

> In our September 2026 scan of adjacent public GitHub projects, we found several recruiting and sourcing tools, but none in the reviewed set centered on the same explicit combination of technical momentum, visibility gap, immutable first-detection history, and historical breakout benchmarking.

The strongest future positioning should come from reproducible benchmark results, not novelty claims alone.
