# Ghost Talent v0.1.0

Ghost Talent v0.1.0 is the first public milestone of an open-source system for discovering emerging AI engineers and researchers from public technical evidence.

## What is included

- wide GitHub repository and contributor discovery
- merged pull-request author discovery
- OpenAlex research evidence
- deterministic Ghost Score
- Contribution Quality inspection
- explainable score drivers
- repository dominance control
- bounded concurrent GitHub enrichment and short TTL caching
- immutable dated Scout snapshots
- first-detected candidate ledger
- Ghost Radar and conservative EARLY SIGNAL detection
- local macOS launcher

## Ghost Score

`0.35 Capability + 0.35 Momentum + 0.20 Visibility Gap + 0.10 Evidence Confidence`

## Ghost Radar

`0.35 Momentum + 0.30 Contribution Quality + 0.25 Visibility Gap + 0.10 Evidence Confidence`

EARLY SIGNAL currently requires merged-PR quality evidence, Momentum >= 60, Visibility Gap >= 45 and Radar Score >= 65.

## Why this release matters

The project now has an end-to-end loop:

`technical topic → discovery → evidence → score → ranking → immutable snapshot → first-detected history`

That creates the foundation for the core research question: can public technical evidence identify breakout AI talent before conventional visibility signals make them obvious?

## Current limitations

- GitHub public events expose a limited activity window.
- OpenAlex identity matching is still conservative and name-based.
- contribution-quality evidence is unavailable for many candidates.
- source APIs may rate-limit or degrade.
- Ghost Score is a discovery signal, not an employment decision or prediction of future success.
